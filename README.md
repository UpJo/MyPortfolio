# John Amba Portfolio

A responsive, static personal engineering portfolio built with HTML, CSS and vanilla JavaScript.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser (or use VS Code Live Server).

## Before publishing — personalize these
- Replace the GitHub and LinkedIn placeholder URLs in `index.html`.
- Confirm the contact email (`johnamba.dev@gmail.com`) is correct.
- Add your actual CV at `assets/John-Amba-CV.pdf`.
- Add real project photographs, demo videos, and repository links as available.
- Check project descriptions for accuracy and update them as you document each build.

## Deploy free
- **GitHub Pages:** create a repository, upload the files, then enable Pages from the repository's Settings.
- **Netlify:** drag the extracted folder into Netlify Drop or connect the GitHub repository.
- **Cloudflare Pages:** connect the repository and use no build command; output directory is the root.

No framework or build step is required.
